# Sovereign Store — next-xus.com

The Federation's store site, built for the next-xus.com domain. Books and resources for sale, with Sovereign Token payment support.

Static HTML storefront. Part of the Federation's commerce layer alongside the Sovereign Emporium.

## Live

https://keywebco.github.io/next-xus-com-sovereign/

(Intended domain: next-xus.com — point the domain's DNS at GitHub Pages and add a CNAME file to go live there.)

## What's here

- **index.html** — the Sovereign Store: Books & Resources
- **assets/** — store assets (images, styles)

## For builders

Static HTML, no build step. Product listings link out to Gumroad/JIM for checkout. To point this at next-xus.com, add a `CNAME` file containing `next-xus.com` and configure DNS.
